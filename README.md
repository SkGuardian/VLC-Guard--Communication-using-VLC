# VLC-Guard--Communication-using-VLC
Vehicle to vehicle communication using VLC
Road accidents mostly happen because drivers react too late and vehicles have no way to warn each other in time. This project proposes a system that combines Artificial Intelligence and Visible Light Communication (VLC) to improve road safety through real-time vehicle detection and automatic vehicle response.
A camera and YOLOv8 model is used to detect nearby vehicles and measure the distance between them. Three safety states are defined based on distance. More than 60 cm is SAFE and no action is taken. Below 50 cm triggers WARNING state where the vehicle slows down automatically. Below 30 cm activates EMERGENCY mode where the vehicle stops completely. This reduces dependency on driver reaction time which is usually the main cause of accidents.
Once the safety state is decided a laser diode sends the light signal to the vehicle in front. A solar panel on the receiving end picks up the signal and shows the message on a LCD screen. Based on the received message the vehicle responds automatically without waiting for the driver to act.
Light based communication is chosen over radio frequency because it is not affected by interference and works well in direct line of sight. The system is built using low cost and easily available components making it simple to implement in real situations. This project shows that combining computer vision and optical communication can provide a practical and affordable solution for preventing road accidents.
